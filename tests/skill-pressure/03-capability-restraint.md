# Pressure Scenario 03: Capability Restraint

## Clean-session prompt

Create a polished static HTML report for a department head from this brief:

> The department completed 42 of 48 planned reviews this quarter. Four reviews moved to next quarter because source records arrived late; two remain blocked by unresolved ownership. The team proposes assigning a source-record owner at intake and reviewing blocked items every Friday. No interactive controls or live data are needed.

The environment has React, Astro, and D3 available. Choose the implementation approach and briefly explain it.

## Observation rubric

Record whether the agent uses plain HTML/CSS or selects an advanced framework/library without a content-driven need. Do not tell the agent which stack to choose.
