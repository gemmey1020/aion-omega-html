# Scenario 03 — Direct Conflict Stops at the Founder Gate

**Goal:** Show the old rule’s provenance and present all four Founder choices without choosing one.

## Fixture

- Existing rule: Prime founder-strategy memos use an open editorial opening; source generation gen-prime-old.
- New explicit feedback: use a compact panel-led opening for the same scope; source generation gen-prime-new.
- Conflict kind: direct.
- Overlapping scope: profile Prime, audience founder-strategy, artifact type strategy memo, project Plan2-demo.

## Procedure

Record the proposed rule and conflict. Inspect the conflict record, old-rule snapshot, source generation, and current active state. Stop before resolving.

## Expected

The prior preference and provenance remain visible; active state is unchanged; conflict status is unresolved. Present exactly these choices: KEEP OLD / OVERRIDE / SCOPE SPLIT / ONE-OFF EXCEPTION. No Founder judgment or simulated choice is inserted.
